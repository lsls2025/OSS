# 3D 迷宫 · 桌面版（暗黑迷宫）

> 基于 Three.js 的 3D 第一人称多人迷宫游戏。玩家在 30×30 的立体迷宫中展开「鬼 vs 成员」对抗：鬼拥有刀人技能追杀成员，成员需躲避追杀、救助同伴并找到两个出口之一逃离迷宫。

---

## 项目简介

「3D 迷宫」是一款运行在浏览器中的 **3D 第一人称多人联机游戏**，采用 **Node.js + WebSocket 服务端权威**架构：服务端负责身份分配、手电电量、刀人/救助/胜负等全部核心规则判定，前端使用 Three.js 渲染 3D 迷宫场景并实时同步所有玩家的位置与状态。游戏支持多名玩家同时在同一个迷宫中对战（狼人杀式捉迷藏），由开发者（房主）控制开局与对局流程。

---

## 功能特性

### 核心玩法
- **鬼 vs 成员对抗**：每局由服务端在开局后随机抽取 1 名「鬼」，其余玩家为「成员」；鬼的目标是击杀全部成员，成员的目标是救助同伴并逃出迷宫。
- **身份隐藏与伪装**：身份公布前所有人外观一致；鬼可以按 `E` 在「成员外观（伪装）」与「鬼形态」之间切换，切换由服务端统一广播，全员同一时刻看到变身。
- **刀人系统**：鬼在鬼形态下累计 10 秒充能即可「刀人」——靠近成员后左键锁定目标，双方定身 5 秒，5 秒内无人救助则被刀者死亡。
- **救助系统**：成员（每局限一次）靠近被刀者后左键打断刀人即可救下同伴；连续 3 次成功打断且期间无击杀，成员方直接获胜。
- **逃脱系统**：迷宫设有两个出口（出口 A 离入口最远，出口 B 在离入口至少半程的边界格中取离 A 最远者），成员走到任意出口即逃脱成功。
- **胜负判定**：鬼获胜 = 对局中所有成员全部被击杀或全部逃出；成员获胜 = 连续 3 次打断刀人（无击杀）。
- **全场断电机制**：鬼首次刀人时，全场（除鬼外）手电被强制关闭一次（每局限一次），被刀者进入 5 秒红屏倒计时。

### 生存机制
- **手电筒电量**：服务端权威管理电池（满电 100），开灯约 60 秒耗尽、关灯约 20 秒充满；电量 ≤1 时强制熄灭。被照亮（灯亮范围）的玩家才会显示身体模型，是黑暗中识别彼此的核心手段。
- **体力系统**：按住 Shift 奔跑消耗体力（满 100 约 10 秒跑空，停下约 5 秒回满，低于 5 不能起跑）；跳跃消耗 5 体力；滞空期间水平移速略快（+15%），「边跑边跳」略快于纯跑。
- **出生点清场与大厅**：迷宫入口处清空墙体，玩家进入后先在此自由活动（预备房），等待开发者开始对局。

### 迷宫生成
- **30×30 格迷宫**：DFS 回溯算法生成 + 固定随机种子（mulberry32），保证所有客户端、每次刷新看到的迷宫完全一致。
- **编织环路**：以 2% 概率打通内部相邻墙（BRAID=0.02），在保留硬核绕度的同时避免一局耗时过长（固定种子实测最短通关约 368 步 / 2.9 分钟）。
- **自动出口选取**：基于 BFS 真实步数自动挑选两个远离入口且彼此分离的出口。

### 多人联机
- **房间隔离**：预备房 / 对局房 / 过渡房（limbo）三方隔离、互不同步；死亡或逃脱后的 5 秒过渡期进入「虚空房」，既不可见也不可被刀，避免状态错乱。
- **断线重连**：60 秒断线档案（token）支持断线重连恢复身份，不产生分身；自动重连采用 2/3/5/8/12/15 秒退避序列。
- **版本握手**：前后端构建号（BUILD / ASSET_VER）联动，浏览器跑旧缓存页面时提示强制刷新，不踢线。
- **房间内聊天**：按回车呼出/发送消息，对局与预备房均可用。

### 开发者模式（房主）
- 快速连按 3 下 `Shift`（每次短按 <180ms、间隔 <250ms）呼出开发者面板，首次需要输入开发者密码（由服务端环境变量 `DEV_PASSWORD` 注入，未配置则禁用）。
- 本地辅助开关：穿墙、连跳（空中无限连跳且不耗体力）、无限体力、增强手电（电量恒满 + 亮度/范围/照射距离暴涨）、移速倍数。
- 房管功能：开始游戏 / 结束游戏、禁用手电（全场强制关灯）、全员锁定（禁止移动）、全员爆点（5 秒内鬼可穿墙看到所有成员位置）、单爆（只报某个成员位置给鬼）、单踢（10 分钟本地封禁）、吸附（把所有玩家拉到自己坐标）、鬼冷却（本端鬼免 10 秒充能）、显示名字（对局中也显示所有人头顶名字，仅本端生效）。

### 体验与兼容
- WebGL 能力预检、老设备低画质档（关闭抗锯齿）、渲染自动降档预热。
- localStorage 不可用时自动降级为内存存储（老内核 / 隐私模式）。
- 被单踢后本地缓存封禁倒计时，到期自动解封。

### 对局流程

1. **进入游戏**：输入昵称进入迷宫出生点（预备房），可自由走动、互相可见，等待开发者开始游戏。
2. **开局**：开发者点击「开始游戏」→ 预备房全员进入对局房 → 5 秒准备提示 → 再 5 秒后由服务端随机抽取并公布「鬼」的身份（在此之前没人知道谁是鬼）。
3. **对抗阶段**：
   - 鬼：按 `E` 变身鬼形态，在鬼形态下累计 10 秒充能；充能满后靠近成员按左键刀人。
   - 成员：用手电观察四周、寻找出口；同伴被刀时靠近后左键救助（每局限一次）；走到绿色光柱出口即可逃脱。
4. **结算**：成员全灭或全逃 → 鬼胜；连续 3 次打断刀人 → 成员胜。结算后全员经 5 秒过渡回预备房，可开下一局。

## 技术架构

```
浏览器（index.html + three.module.js）
   │  WebSocket（/ws3d，JSON 消息）
   ▼
Node.js 独立后端（server.js，http + ws）
   ├── 静态文件服务（gzip 压缩缓存 + 版本化长缓存 / html no-store）
   ├── 手电筒电量（服务端权威）
   ├── 房间管理（prep 预备房 / match 对局房 / limbo 过渡房）
   ├── 对局控制（开局、抽鬼、公布身份、结束）
   ├── 刀人 / 救助 / 胜负判定（服务端权威守卫）
   ├── 断线重连（60 秒 token 档案）
   └── 心跳与对账（ping/pong、全量对账、电池广播）
```

- **前端**：原生 HTML/CSS/JavaScript（ES Module），Three.js 引擎以本地 `three.module.js` 加载（带版本号参数长缓存）。
- **后端**：Node.js + `http` + `ws`（WebSocketServer），单进程独立后端，同时承担静态资源托管与 `/ws3d` 多人 WebSocket。
- **服务端权威**：移动钳位、手电电量、身份分配、刀人/救助/胜负判定、变身换图全部由服务端裁决，客户端只做本地预测与渲染。
- **同步机制**：2 秒全量对账、250ms 电量广播、3 秒悬空兜底、10 秒心跳（2 秒 pong 宽限）。
- **缓存策略**：版本化资源（`?v=`）`max-age=31536000, immutable`；`index.html` 与未带版本号资源 `no-store`；文本类资源按需 gzip（内容逐字节比对防陈旧压缩）。
- **安全**：开发者密码从环境变量注入（`DEV_PASSWORD` / `DEV_ROLE_PASSWORD`），未配置则开发者功能自动禁用。

## 运行与启动

### 环境要求
- Node.js（需支持 `ws` 模块）
- 现代浏览器（支持 WebGL 与 ES Module；IE11 / 老版 Edge 无法运行）

### 启动步骤

```bash
# 1. 进入项目目录
cd D:\暗黑迷宫

# 2. 安装依赖（只需 ws）
npm install ws

# 3. 启动服务器（默认端口 9090）
node server.js

# 4. 浏览器访问
http://localhost:9090
```

### 环境变量

| 变量 | 说明 | 默认值 |
|---|---|---|
| `PORT` | 服务监听端口 | `9090` |
| `DEV_PASSWORD` | 开发者面板密码（未配置则开发者功能禁用） | 无 |
| `DEV_ROLE_PASSWORD` | 角色卡开发者入口密码（未配置则禁用） | 无 |

服务器监听 `0.0.0.0`，局域网内其他设备可通过 `http://<本机IP>:9090` 直接加入；生产环境可置于反向代理（如 Nginx/宝塔）之后。
